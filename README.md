# DevLex — Digital Law for Builders

DevLex is a bilingual Arabic/English front-end prototype for a LegalTech platform intended for developers, startups, product teams and companies. The visual direction combines a custom geometric DevLex mark, vivid violet/aqua/lime/pink accents, a dashboard-style hero, searchable legal reference cards, workflow sections and a separate contact page.

## Files
- `index.html` — landing page, legal library, how-it-works section, benefits, pricing, about section and demo subscription modal.
- `contact.html` — standalone contact page.
- `styles.css` — responsive design system, vivid color palette, custom wordmark/mark treatment and mobile styles.
- `script.js` — bilingual UI, search, filters, legal reference modals and demo checkout behavior.

## Preview
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Open `contact.html` to see the separate contact page.
4. The language selection is stored in browser local storage. Google Fonts require internet access; fallback fonts are provided.

## Important before launch
- This is a front-end prototype, not a production platform or legal advice service.
- Verify every legal summary, scope, amendment, implementing regulation and official source before publication. Treat all cards as draft educational summaries.
- The contact email `hello@devlex.example` is a placeholder. Replace it with a real monitored mailbox. The contact form opens a visitor's email app; it does not send to a server.
- The Builder plan is priced at **199 MAD/month** as requested, but payment is only a demo. No payment data is collected and no subscription is activated.
- Real subscriptions require user accounts, a secure backend, a database, server-side access control, payment-provider integration suitable for Morocco, verified webhooks, cancellation/refund handling and customer support. Never process card data in front-end JavaScript.
- Before launch, prepare privacy terms, terms of service, refund/cancellation rules and suitable legal-information disclaimers, and assess applicable Moroccan data-protection requirements.
- Do not advertise planned features as available until implemented and tested.
